# MDFレーザーカット用 Fusion アドイン v0.1

実行ボタン、警告確認、板状ソリッドの輪郭抽出、配置、mm単位DXF出力を実装しました。Fusion内の動作確認はこれからです。

## 最初の起動

1. Fusionで「ユーティリティ」→「スクリプトとアドイン」を開きます。
2. 「アドイン」から`FusionSheetLayout`を選びます。実行中なら一度「停止」してから「実行」します。
3. デザインのユーティリティ／アドインパネルに「MDFレーザーカット出力」が表示されます。見つからない場合はパネル内のメニューか、Sキーのコマンド検索で名前を探してください。

既存の起動成功メッセージとサンプルコマンドは残しています。ボタンが更新されない場合はFusionを再起動してからアドインを実行してください。

## 使い方

1. 板状ボディのあるデザインを開き、スケッチ編集を終了します。
2. 「MDFレーザーカット出力」を押します。解析と配置が始まります。
3. 警告があると一覧が表示されます。「無視」は警告対象を除き正常な部品のみ出力、「キャンセル」は終了です。出力できる部品がなければ閉じる操作だけになります。
4. DXFの保存先を選びます。警告がない場合は直接この画面へ進みます。保存画面でもキャンセルできます。
5. 結果ログはアドイン内の`logs`フォルダに`出力名_結果_日時.txt`として保存されます。

「無視」で不適合な形状まで出力されることはありません。部分出力の場合は、結果一覧で部品数を確認してください。

## 設定

「MDF出力設定」で変更できます。初期値は表示中のみ、板厚2.5±0.05mm、部品間隔3mm、配置幅600mmです。設定はアドインの実行中だけ保持します。配置高さは無制限です。

対応する輪郭は直線・円・円弧です。貫通穴や切り欠きに対応し、段差、ポケット、面取り、自由曲線、判定できない面分割などは警告して除外します。元モデルは変更しません。

## 確認してほしいこと

- まず100×50×2.5mmの板を出力し、DXFを加工ソフトでmmとして開いて100×50mmか測ります。
- 貫通穴付き板と厚さ3mmの板を一緒に置き、警告一覧で3mmの板が除外されるか確認します。
- 警告画面の「キャンセル」でファイルが作られないこと、「無視」で正常な板だけが保存されることを確認します。
- 同じ部品のオカレンスが複数あるときの数量、非表示対象、元モデルに変更がないことを確認します。

不具合があれば、画面のエラー全文または`_結果.txt`と、対象ボディの形状を共有してください。

## 保存先の変更（2026-10-21）

結果ログは、このアドインの`logs`フォルダに保存します。フォルダがなければ作成します。ログ保存に失敗してもデスクトップやDXFの保存先へ代替保存しません。DXFは保存ダイアログでユーザーが選んだ場所へ保存します。ダイアログの初期フォルダはアドインフォルダです。デスクトップへ自動保存しません。


## SVG出力の追加（2026-10-21、本節を優先）

「MDF出力設定」の「出力形式」でDXF／SVGを選択できます。初期値はDXFです。設定を保存し、「MDFレーザーカット出力」を押すと、選択形式の保存ダイアログが開きます。設定はアドイン実行中に保持します。

SVGも同じ形状判定・警告確認・配置処理を使用します。外周と穴を別の閉じた輪郭として保持し、直線はパス、円弧はSVGのA命令、円はcircle要素で出力します。折れ線へ近似しません。幅・高さをmmで明記し、viewBoxの1単位を1mmに対応させます。SVGの下向きY座標へ変換すると同時に円弧の向きも変換し、形状を鏡像にしません。塗りなし・黒線、表示線幅0.1mmです。線の中心が切断輪郭で、線幅を切りしろとして加算しません。加工ソフトではベクター輪郭として扱ってください。

保存前にXML・寸法・輪郭数・円弧パラメーターを検証します。出力先はユーザーが保存画面で選択し、初期フォルダはアドイン内です。結果ログは引き続きアドイン内logsへ保存し、選択形式も記録します。既存SVGの上書きも確認と1世代バックアップを行います。

Fusionでの操作と使用する加工ソフトへのSVG読み込みはユーザーが確認してください。100mmの辺・穴径が正しく読み込まれることを確認します。

SVG円弧の参照: https://www.w3.org/TR/SVG2/paths.html


## 読み込み互換性の修正（2026-10-21）

ユーザー提供DXFには22個の図形要素、SVGには83×20mmの範囲に2部品・3輪郭が存在しました。DXFは管理情報を省略した構成だったため、BLOCK_RECORD、BLOCKS、OBJECTS、レイアウト、および各図形のモデル空間所有者参照を含むR2000テンプレートを使用する方式へ変更しました。実行時の外部ライブラリは不要で、dxf_template.txtを同梱します。SVGは各輪郭へ明示的に線色・塗りなし・表示線幅0.1mmを指定します。切断中心線の座標は変更しません。

提供ファイルの修正版を別名で作成し、元ファイルは変更していません。DXFの図形座標・要素種類を比較し、独立した読み取り監査が修復なしで通ることを確認しました。アドイン候補も同じ形状で検査し、全自動試験48件が合格しました。SVGが空に見える原因とFusionでの読み込み成功は実機未確認です。修正版の再読み込みで確認します。ログ保存先はアドイン内logsのままです。



## 板厚方向が複数ある場合の出力（2026-10-21、本節を優先）

MDF出力設定に「板厚方向が複数候補でも警告付きで出力する」を追加しました。初期値はOFFです。ONの場合、一様な板形状として検証を通過した候補のうち、板面積最大のものを1つ選びます。同面積では法線の主軸X/Y/Z順、その後に法線成分の順で選びます。候補数・選択厚さ・2D寸法・法線を警告に記録し、「無視」で出力します。「キャンセル」は出力しません。選択候補が配置幅を超える場合は通常どおり除外します。DXF/SVG共通です。

板厚範囲外、段差、未対応形状を強制出力する機能ではありません。結果ログには設定のON/OFFと選択理由を記録します。OFF時の除外、ON時の最大板面選択、同面積の決定性、解析一覧への採用、厚さ不一致の除外を追加試験し、全53件が合格しました。実Fusionの動作はユーザー確認待ちです。

## Git管理フォルダへの移行（2026-10-22）

開発・実行の正本は `FusionSheetLayout` フォルダです。Fusionから読み込む入口は `FusionSheetLayout.py` と `FusionSheetLayout.manifest` です。

1. Fusionで旧 `mdf_アドイン` が動いている場合は停止します。
2. 「スクリプトとアドイン」で `FusionSheetLayout` を選びます。表示されない場合はこのフォルダを追加します。
3. 新しいアドインを実行します。同じコマンドIDを使うため、旧版と同時に実行しないでください。

旧フォルダは復旧用に残しています。ログ・キャッシュ・バックアップ・個人用エディター設定は移行せず、Git管理から除外しています。新しいログは実行時にこのフォルダのlogsへ作成されます。SVGの出力先はユーザーが選択します。リポジトリ内に保存した生成SVGは、ソース用アイコンと区別するため、コミット前に対象を確認してください。

既存のLICENSEと.gitattributesは維持しました。移行時点のローカルGitにはリモートURLがありませんでした。GitHub同期の接続設定は別途確認が必要です。この移行ではcommit・pushを行っていません。
