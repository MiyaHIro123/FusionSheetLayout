# FusionSheetLayout (FusionAddin)

Autodesk Fusionで設計した板状ソリッドボディを、MDFレーザーカット用の2Dデータに変換するPythonアドインです。複数部品の輪郭を平面上に並べ、1つのDXFまたはSVGとして出力します。

現在のバージョンは **v0.1（開発中）** です。

## 主な機能

- 元の3Dモデルを変更せずに、板状ボディの外周・貫通穴・切り欠きを抽出
- 直線・円・円弧を保持した2D輪郭の出力
- 2D外接矩形が重ならない配置と、部品間隔・配置幅の設定
- mm単位のDXF／SVG出力
- 出力前の警告一覧と「無視」「キャンセル」の選択
- 表示／非表示の対象設定と、アドイン内への結果ログ保存

## ★ Fusionへの導入方法

Autodesk Fusionのデスクトップ版で使用できます。

Fusionに内蔵されているPythonで動作するため、**Pythonや追加ライブラリのインストールは不要**です。

Windows環境で開発・動作確認しています。macOSでの動作は未確認です。

### 1. アドインのダウンロード

1. [GitHub Releases（配布ページ）](https://github.com/MiyaHIro123/FusionSheetLayout/releases) を開く
2. インストールするリリースの説明を確認し、**「Assets」** を開く
3. 添付されている配布用ZIP（例：`FusionSheetLayout-v0.1.zip`）をダウンロードする
   - `Source code (zip)` や `Source code (tar.gz)` ではなく、リリースに添付された **`FusionSheetLayout-….zip` の配布ファイル**
4. ダウンロードしたZIPを右クリックし、**「すべて展開」** を選びます。
5. 展開した中の **`FusionSheetLayout` フォルダ**を、ドキュメントなどの削除しない場所に移動
   - このフォルダの直下に `FusionSheetLayout.py` と `FusionSheetLayout.manifest` があることを確認してください。
   - フォルダ名は `FusionSheetLayout` のままにしてください。

参考：フォルダの中身
```text
FusionSheetLayout/
├── FusionSheetLayout.py
├── FusionSheetLayout.manifest
├── AddInIcon.svg
├── config.py
├── commands/
└── lib/
```

※ ダウンロードしたフォルダは、ドキュメントなどの削除しない場所に保存してください。インストール後も必要になります。

### 2. Fusionにアドインを登録

1. **Autodesk Fusion** を起動
2. 「デザイン」ワークスペースの **「ユーティリティ」→「スクリプトとアドイン」** を開く
3. **「アドイン」** タブを選択
4. **「＋」** ボタンをクリックし、既存のアドインを追加
   - Fusionのバージョンによっては「デバイスからスクリプトまたはアドイン」と表示されます。
5. 先ほど展開した **`FusionSheetLayout` フォルダ** を選択
6. アドイン一覧に表示された `FusionSheetLayout` を選択し、**「実行」** をクリック

### 3. アドインを使用する

登録が完了すると、Fusionの「ユーティリティ」にあるアドインパネルから、次の機能を使用できます。

- **MDFレーザーカット出力**
- **MDF出力設定**

毎回Fusionを起動したときに自動でアドインを使用できるようにするには、「スクリプトとアドイン」の一覧で **「起動時に実行」** を有効にしてください。

### 補足・注意事項

- アドインのフォルダを削除・移動すると、起動できなくなる場合があります。
- 新しいバージョンを導入する場合は、実行中のアドインを停止してからファイルを更新してください。
- 以前のバージョンを別の場所に登録していた場合は、古いアドインを停止し、自動起動も解除してください。

登録操作の詳細は、[Autodesk公式：スクリプトとアドインの管理](https://help.autodesk.com/cloudhelp/ENU/Fusion-Model/files/SLD-MANAGE-SCRIPTS-ADD-INS.htm) を参照してください。

## 使用方法

1. 板状ソリッドボディを含むデザインを開き、スケッチ編集を終了します。
2. 出力対象のボディを表示します。初期設定では非表示のボディは除外されます。選択中のボディだけを出力する方式ではありません。
3. 「MDF出力設定」で出力形式・部品間隔・配置幅などを指定し、「設定を保存」を押します。
4. 「MDFレーザーカット出力」を押すと、対象ボディの解析と配置が始まります。
5. 警告が表示された場合は、警告内容と「出力部品」の一覧を確認します。「無視」で一覧の部品を出力し、「キャンセル」でファイルを作成せず終了します。警告がなければ保存画面に進みます。
6. DXFまたはSVGの保存先とファイル名を選びます。保存画面でもキャンセルできます。
7. 完了画面で部品数を確認し、加工ソフトで読み込んで寸法・穴・数量を確認します。

出力可能な部品がない場合は保存に進みません。同じコンポーネントが複数配置されている場合は、表示設定に従い、それぞれを別部品として扱います。

## 設定

| 項目 | 初期値 | 内容 |
| --- | --- | --- |
| 出力形式 | DXF | DXFまたはSVGを選択 |
| 非表示のボディも含める | OFF | ONで非表示の対象も解析 |
| 板厚許容誤差 ± | 0.05mm | 公称板厚2.5mmに対する許容差。設定範囲は0より大きく0.25mm以下 |
| 部品間隔 | 3mm | 配置時の外接矩形間隔。0mm以上 |
| 配置幅 | 600mm | 配置する横幅。0mmより大きい値 |
| 板厚方向が複数候補でも警告付きで出力する | OFF | 有効な板厚方向が複数ある部品の出力を許可 |

公称板厚は2.5mm固定です。設定はアドイン実行中のみ保持され、再起動後は初期値に戻ります。配置高さに上限はなく、自動回転や材料使用量を最小化する配置には対応していません。

### 板厚方向が複数候補になる場合

設定がOFFの場合、その部品を警告して除外します。ONの場合は、形状検証を通過した候補のうち板面積が最大の方向を選び、出力前に警告します。「無視」を選ぶと、その部品も出力します。

この設定は板厚不一致や段差のある部品を強制出力するものではありません。対象外形状や配置幅を超えた部品は、「無視」を選んでも出力されません。

## 対応する形状と制限

対象は、一定厚で、単純なレーザー切断で再現できる板状ソリッドボディです。輪郭が直線・円・円弧で構成された貫通穴や切り欠きに対応します。

以下は警告してスキップします。

- 板厚が許容範囲に入らないボディ
- 段差、ポケット、面取りなど、厚さ方向に形状が変化する部品
- 自由曲線やメッシュなどの未対応形状
- 面の分割などにより、一様な板として判定できない形状
- 設定した配置幅に収まらない部品

元モデルへの変更や、出力用の一時スケッチの作成は行いません。切りしろ補正は行わないため、必要な補正は加工ソフト側で設定してください。

## 出力ファイルと結果ログ

- **DXF**：R2000形式、mm単位。直線・円・円弧を図形要素として出力します。
- **SVG**：幅・高さをmmで指定し、viewBoxの1単位を1mmに対応させます。塗りなし・黒線・表示線幅0.1mmで出力します。線幅は切りしろではなく、線の中心が切断輪郭です。
- **保存先**：出力ファイルは保存画面で指定します。初期フォルダはアドインフォルダです。
- **結果ログ**：出力後、アドイン内の `logs/` に設定・部品一覧・警告などを保存します。ログ保存だけが失敗した場合は、出力ファイルが保存済みであることを画面に表示します。

既存の出力ファイルを上書きする場合は確認画面が表示され、同じ場所に `名前(バックアップ).拡張子` として直前の1世代を残します。結果ログにはモデル名や保存先が含まれるため、不具合報告に添付する際は内容を確認してください。

## 初回の確認とトラブルシューティング

初回は100×50×2.5mmの板など、寸法が分かる小さなモデルで試してください。読み込み先で100×50mmになっていること、穴径・部品数・配置が正しいことを確認してから加工に使用します。

| 症状 | 確認すること |
| --- | --- |
| アドインを追加できない | フォルダ名と入口ファイルが `FusionSheetLayout`、`FusionSheetLayout.py`、`FusionSheetLayout.manifest` で一致しているか確認 |
| ボタンが表示されない | デザインワークスペースとアドインパネルのメニューを確認。アドインを停止して再実行し、必要ならFusionを再起動 |
| 出力できる部品がない | 警告一覧、ボディの表示状態、板厚、配置幅を確認 |
| DXFを読み込めない／SVGが空に見える | 読み込み単位をmmにして全体表示し、別形式でも確認。互換性の問題は現在確認中 |
| ログを保存できない | アドインフォルダに書き込み権限があるか確認 |

不具合を報告する場合は、Fusionのバージョン、OS、設定、再現手順、エラー全文、結果ログを添えてください。形状に依存する場合は、共有可能な最小モデルもあると原因を確認しやすくなります。

## 更新方法

1. Fusionの「スクリプトとアドイン」で、実行中の `FusionSheetLayout` を停止します。
2. 現在のアドインフォルダを別の場所にコピーしてバックアップします。
3. [GitHub Releases](https://github.com/MiyaHIro123/FusionSheetLayout/releases) から新しいリリースの配布用ZIPをダウンロードし、展開します。
4. 展開した `FusionSheetLayout` フォルダの中身を、現在登録しているアドインフォルダに上書きコピーします。
   - 設定を引き継ぐため、既存の `settings.json` は削除・上書きせずに残してください。
5. Fusionでアドインを再実行します。旧版と新版を同時に起動しないでください。
